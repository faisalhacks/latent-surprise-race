\section{Results}
\label{sec:results}

\subsection{Registered experiment: \texorpdfstring{\pending}{pending}}

The registered Phase~2 experiment --- 1000 anomalous and 200 control clips at
$256$~px through frozen V-JEPA 2, under the protocol of
Sections~\ref{sec:method} and~\ref{sec:protocol} --- has \textbf{not been run}.
It requires approximately one GPU-hour of credit that was not available; the
harness is complete, tested, and launch-ready, and the run is recorded with its
exact launch command in the repository's parked-experiment register.

Consequently this section reports \textbf{no registered results}. We have
deliberately not filled the gap with illustrative, estimated or placeholder
numbers. The manuscript is generated from run outputs by a script
(Section~\ref{sec:reuse}); with no run analysed, that script emits visible
\textsc{pending} markers rather than plausible values, and the following
quantities are all \pending:

\begin{itemize}
\item detection latency per monitor, under both threshold regimes;
\item the paired probe-versus-baseline contrasts and their corrected $p$-values;
\item Kaplan--Meier curves and the restricted mean detection latency;
\item per-anomaly-family breakdowns;
\item the lift of each monitor, and therefore whether either baseline fires at
chance;
\item the Phase~3 gate verdict.
\end{itemize}

We state plainly that the central empirical question of this work --- whether
representation geometry crosses an alarm threshold sooner than the model's own
prediction error --- \textbf{remains open}. Nothing below should be read as
bearing on it.

\subsection{Exploratory CPU pilot (not the registered experiment)}
\label{sec:pilot}

To size the registered run and sanity-check the pipeline against real
pretrained weights, we began a reduced-resolution pilot on CPU. It is
\textbf{exploratory}, it is \textbf{not} the registered experiment, and it
cannot substitute for one.

\begin{itemize}
\item \textbf{Resolution.} $128$~px rather than the registered $256$~px, which
shrinks the patch grid from $16\times16$ to $8\times8$. Context length, tubelet
size, all probe definitions, the $\mathcal{L}_0$ construction, thresholds and
metrics are unchanged. We rejected $96$~px because the disc would then be
smaller than a single patch.
\item \textbf{Scale.} A reduced design of \lgwPilotTarget{} clips rather than
$1200$.
\item \textbf{Status at the time of writing:} \lgwPilotTotal{} of
\lgwPilotTarget{} clips extracted --- \lgwPilotCalib{} calibration controls,
\lgwPilotEval{} evaluation controls, \lgwPilotAnom{} anomalous. The run is
\lgwPilotState.
\end{itemize}

\textbf{No analysis of the pilot is reported here.} Thresholds are calibrated on
control clips, so until the control splits are complete no threshold exists, no
alarm time is defined, and no detection latency can be computed. Reporting
partial anomaly data without calibrated thresholds would be meaningless rather
than merely preliminary. The pilot ordering was arranged so that controls are
extracted first, precisely so that an interrupted run becomes a smaller but
coherent experiment rather than an incoherent one; at the time of writing that
threshold has not yet been crossed.

Two observations from a two-clip correctness check on the real pretrained
weights are reported in Section~\ref{sec:limitations} as risks to the registered
run's power. They concern the \emph{magnitude and dispersion} of monitor scores,
not detection latency, and they are not results about the hypothesis.

\subsection{What the harness does produce}

The apparatus itself is verified, and these are results about the protocol
rather than about world models:

\begin{itemize}
\item Every monitor is a streaming object that cannot reference a future frame.
Inverting all frames after a cut point leaves $z_t$, $\mathcal{L}_0$ and all
three probes bit-identical for $t$ at or before the cut, including against the
real V-JEPA 2 architecture.
\item The $\mathcal{L}_0$ prediction does not move when only the predicted
frames change, and does move when $f_{t-2}$ changes --- so the causality
guarantee is not satisfied vacuously by a prediction that ignores its input.
\item Probe values match their closed forms to $10^{-9}$, and the $O(k^2 d)$
covariance identity of Section~\ref{sec:method} matches the naive $d \times d$
computation to machine precision.
\item Thresholds are a function of calibration controls alone.
\item Both registered adapters --- V-JEPA 2 and VideoMAE --- pass the identical
contract suite.
\item The full orchestration, including fan-out, merge, analysis and the gate,
was exercised end-to-end at the full $1200$-clip scale using randomly
initialised weights, so the only unexercised step in the registered run is the
GPU forward itself.
\end{itemize}
